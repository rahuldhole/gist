Deployment Tips
  • Voice loading: voices load asynchronously. Listen for voiceschanged.
  • Autoplay: browsers require a user gesture (click/tap) before speaking.
  • Long text: Chrome can cut off after ~15s. This app (and the snippet) splits text into sentences.
  • Highlighting: network voices and some mobile browsers don't emit word events, so the current sentence is highlighted instead.
